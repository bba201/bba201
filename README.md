* Fingers temperature sensor.
  Components: x3 1000 Ω resistors, x3 leds, x1 TMP36. Description: in this project, I measured my room's base temperature with the converted celsius value from the TMP36 through the serial monitor, then I settled a constant with it's value. After that I created some conditions to light up some leds, each time that the sensor's temperature incresed 2 celsius degrees the digital pins would turn on the led's one by one. To the sensor gain some temperature I wrapped my fingers around the sensor and then watched the leds turn on as the temperature increased.
  Code: https://github.com/bba201/chill_o_meter
  Vídeo: https://youtube.com/shorts/p-tPOPYmsYU
