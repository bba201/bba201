* Fingers temperature sensor.
  Components: x3 1000 Ω resistors, x3 leds, x1 TMP36. Description: in this project, I measured my room's base temperature with the converted celsius value from the TMP36 through the serial monitor, then I settled a constant with it's value. After that I created some conditions to light up some leds, each time that the sensor's temperature incresed 2 celsius degrees the digital pins would turn on the led's one by one. To the sensor gain some temperature I wrapped my fingers around the sensor and then watched the leds turn on as the temperature increased.
  Code: https://github.com/bba201/chill_o_meter
  Vídeo: https://youtube.com/shorts/p-tPOPYmsYU

* Servo motor rotaton with analog values from a potentiometer.
  Components: 2x Capacitors, 1x potentiometer, 1x servo motor with arm. Description of the project: On this project, I used the analog values from a potentiometer as I rotated it to rotate an arm attache to a servo motor.
  Code: https://github.com/bba201/mood_cue
  Vídeo: https://github.com/user-attachments/assets/db1c4bd0-5bc6-4959-84db-ef76e2ac5c2c

* Mini keyboard. Conponents: 4x pushbuttons, 2x 4.7kΩ resistors, 1x 1kΩ resistor, 1x 1MΩ resistor, 1x piezo. Description of the project: In this project, I built a resistor ladder with 4 buttons in parallel to get different analog values from the circuit, then I made those different 4 analog values from the buttons correspond to different frequencies to play on the piezo, so, as I pressed different buttons, the piezo would play different notes (frequencies).

  Code: https://github.com/bba201/keyboard
